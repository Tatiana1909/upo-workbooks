# Сервер результатов рабочих тетрадей

Сервис принимает вход по единому коду курса и ФИО, хранит прогресс двух курсов в SQLite и выгружает сводный CSV для администратора.

1. Скопируйте `.env.example` в `.env` и задайте три длинных случайных секрета.
2. Запустите `docker compose up -d --build`.
3. Текущая временная публикация использует порт `8081`; при появлении домена сервис можно перенести за HTTPS reverse proxy.
4. Статические страницы и API обслуживаются одним контейнером, поэтому адрес API определяется автоматически.

Проверка: `GET /health`.

Выгрузка итогов: `GET /api/v1/admin/results.csv` с заголовком `X-Admin-Key`.
