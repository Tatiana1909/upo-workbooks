# Сервер результатов рабочих тетрадей

Сервис принимает вход по единому коду курса и ФИО, хранит прогресс и историю попыток двух курсов в SQLite. В отдельном кабинете администратора доступны дашборд, таблица результатов, карточки участников и выгрузка CSV.

1. Скопируйте `.env.example` в `.env`, задайте секреты, логин и пароль администратора.
2. Запустите `docker compose up -d --build`.
3. Текущая временная публикация использует порт `8081`; при появлении домена сервис можно перенести за HTTPS reverse proxy.
4. Статические страницы и API обслуживаются одним контейнером, поэтому адрес API определяется автоматически.

Проверка: `GET /health`.

Кабинет администратора: `/v2/admin.html`.

Выгрузка итогов: `GET /api/v1/admin/results.csv` с Bearer-токеном администратора или служебным заголовком `X-Admin-Key`.
