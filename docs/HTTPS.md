# HTTPS для учебных тетрадей

Адрес после включения: https://194.48.140.70/v4/index.html. Доверенный сертификат выдаётся для IP-адреса, домен не требуется. Старые HTTP-ссылки на порту 8081 перенаправляются на тот же путь по HTTPS.

Отдельный шлюз workbook_https обслуживает порты 80, 443 и старый адрес 8081. Приложение доступно только локально на 127.0.0.1:18081. Существующий том данных приложения сохраняется. NIE, VPN и другие контейнеры не меняются.

Сертификаты и ACME-ключи хранятся исключительно в закрытом каталоге /opt/upo-workbooks/https/letsencrypt на сервере. Они не включаются в GitHub или образ контейнера. Прежде чем запросить доверенный сертификат, сценарий проверяет маршрут ACME через тестовый центр выдачи.

Таймер ifcm-workbooks-cert-renew.timer проверяет необходимость продления дважды в сутки. После успешного запуска Certbot конфигурация шлюза проверяется и перечитывается. Тест продления выполняется при первоначальной настройке. Работа таймера не зависит от GitHub.

Перед переключением создаётся проверенная резервная копия данных и серверных настроек. При ошибке активации сценарий восстанавливает прежние привязку порта и настройки приложения. Повторный запуск установки при занятых портах останавливается: существующие службы не заменяются автоматически.

Для проверки оператором сервера:

```bash
systemctl status ifcm-workbooks-cert-renew.timer
journalctl -u ifcm-workbooks-cert-renew.service
/usr/local/sbin/ifcm-workbooks-cert-renew
```

После перехода с HTTP потребуется повторный вход: браузер хранит сеансы отдельно для разных адресов. Результаты обучения при этом сохраняются на сервере.
