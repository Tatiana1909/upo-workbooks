# Приёмка и сроки хранения 29 октября 2026 года

Изменения подготовлены поверх актуальной основной версии
`9175b5acc3e742e3f36109f1379c7e9c126a6c7d`.
Это промежуточный технический протокол, а не финальное ТЗ или акт приёмки.

## Подготовленные изменения

- Ответы, заметки с ответами и скриншоты очищаются через шесть календарных
  месяцев после завершения, для незавершённых попыток — после последнего
  сохранения. Для отправленного экзамена ПБ используется дата отправки.
- Итоговые баллы, даты, номера попыток и проверки преподавателя сохраняются.
- Просроченную попытку нельзя повторно заполнить из старой вкладки;
  пользователь видит пояснение и может начать новую попытку.
- Обработка выполняется при старте приложения и каждые шесть часов.
  Восстановленная копия обрабатывается до приёма запросов.
- Неудалённые из-за файловой ошибки скриншоты остаются в очереди повторной
  очистки, а API больше не выдаёт их участникам.
- Проверенные резервные копии старше 14 дней удаляются после успешной новой
  проверки. Последняя исправная точка, частичные и посторонние каталоги
  автоматически не удаляются.
- Браузерные тесты обновлены под действующий интерфейс приглашений и
  автоматический переход участника к назначенной тетради.

## Выполненные проверки

Полный серверный набор проверяет версии, роли, аккаунты, приглашения,
табельные номера, тёзок, CSV, оценки, повторную проверку работ, импорт трёх
тетрадей, группы сводки и резервные архивы. Дополнительные проверки хранения
охватывают точную границу срока, високосный год, завершённые и незавершённые
попытки, неизменность баллов, удаление изображений и новую попытку.

В браузере пройдены:

1. Создание участника, приглашение, самостоятельная регистрация, переход в
   назначенную тетрадь и сохранение ответа; мобильный экран 390 px.
2. Редактор ПБ, шесть разделов, изменение ссылки, сохранение, предпросмотр,
   переключение сценариев задымления и каталог; экран 390 px.
3. Обе тетради УПО при 1440 и 390 px, сообщение об истечении срока и новая
   попытка, выбор курса в общей сводке. Проверка выполнялась на синтетических
   данных в отдельной локальной базе.

## Оставшиеся условия

Изменения пока не опубликованы на рабочем сервере. Внешняя среда проверки
получает ошибку соответствия сертификата по адресу
`https://194.48.140.70/v4/index.html`; для диагностики подготовлен отдельный
сценарий, проверяющий HTTPS непосредственно на рабочем сервере, API готовности,
страницы входа, таймер копирования и целостность базы без изменения данных.

До финального ТЗ требуется подтвердить результаты этого сценария, повторить
проверки после серверного обновления и проверить контейнерное восстановление.
VPN и внешнее хранилище остаются отложенными по решению Владельца продукта.
